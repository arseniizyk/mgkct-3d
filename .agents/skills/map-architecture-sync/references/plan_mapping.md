## 2. Координатная сетка, константы и URL-параметры отладки

- **Ось X**: Запад (-) ↔ Восток (+)
- **Ось Y**: Высота (подъем между этажами `BASE_FLOOR_STEP = 2.65`)
- **Ось Z**: Север (-) ↔ Юг (+)
- **Высота стен в 2D/3D**: `BASE_WALL_HEIGHT = 0.35` (обеспечивает читаемость стен сверху без перекрытия коридоров)
- **Толщины стен**:
  - Наружные капитальные стены: `OUTER_T = 0.24` (или `0.28`)
  - Внутренние перегородки: `INNER_T = 0.18` (или `0.14`)

### Центры корпусов (для фокусировки камеры)
- **Корпус 1**: `X = 1.0, Z = -2.0`
- **Корпус 2**: `X = 44.2, Z = -5.1`
- **Корпус 3**: `X = 5.9, Z = -40.2`
- **Корпус 4**: `X = 48.5, Z = -44.5`
- **Все корпуса ('both')**: `X = 16.0, Z = -18.0`

### URL-параметры позиционирования и отладки в браузере
При открытии `index.html` поддерживаются query-параметры:
- `?bldg=<1..4>&floor=<1..7>` — изолирует выбранный корпус и этаж.
- `&top=1` — включает строгую телецентрическую (ортогональную) проекцию сверху (`fov = 6` с компенсацией дистанции), устраняющую перспективный наклон стен на краях экрана.
- `&grid=1` — рисует поверх 2D-карты мировую координатную сетку `(X, Z)` с шагом 1 м и подписями каждые 2 м.
- `&bti=1` — накладывает полупрозрачный план БТИ (`planning_zip/Корпус B/F.jpg`) прямо на 3D-плиту этажа в мировых координатах.
- `&debug=1` — включает одновременно сетку (`grid=1`), подложку БТИ (`bti=1`) и подсветку дверных проемов.

## 3. Инструменты автоматического харнеса (`.agents/skills/map-architecture-sync/scripts/`)

1. **`capture_floor.js`** (`node .agents/skills/map-architecture-sync/scripts/capture_floor.js --building <B> --floor <F>` или `--all`):
   Генерирует в `.agents/skills/map-architecture-sync/captures/` три файла для каждого этажа:
   - `render_bldg<B>_floor<F>.png` — чистый ортогональный 2D-вид этажа.
   - `overlay_bldg<B>_floor<F>.png` — совмещенный оверлей: красный план БТИ + синие 3D-стены + зеленые двери + метровая сетка `(X, Z)` + координаты центров комнат.
   - `nav_bldg<B>_floor<F>.png` — визуализация графа навигации `A*` поверх стен и плана БТИ.
2. **`validate_floor.js`** (`node .agents/skills/map-architecture-sync/scripts/validate_floor.js [--building <B> --floor <F>]`):
   Автоматический линтер геометрии и навигационного графа:
   - Проверяет отсутствие пересечений ребер `A*` со стенами (`WALLS_REGISTRY`).
   - Проверяет 100% связность графа на этаже и привязку каждого кабинета из `ROOMS_REGISTRY`.
   - Проверяет соосность лестничных маршей (`ЛК-1..3`) между этажами.
3. **`straighten_plan_labels.py`** (`python3 .agents/skills/map-architecture-sync/scripts/straighten_plan_labels.py`):
   Выравнивает вертикальные и перевернутые номера помещений на чертежах `planning_zip/` строго горизонтально, используя 3-пиксельную защитную маску стен (`connectedComponentsWithStats`), чтобы ни один пиксель стены или двери не был задет.

## 4. Основные геометрические функции (`js/helpers.js`)

### Создание стен с проемами и дверями
```javascript
addWallLine(targetGroup, x1, z1, x2, z2, openings, thickness, isExterior, isColumn)
```
- `openings` — массив проемов/дверей:
  `[{ from: 4.6, to: 7.2, type: 'door' }, { from: 10.0, to: 11.2, type: 'open' }]`
  - `type: 'door'` — оставляет проем в стене и добавляет 3D дверное полотно с коробкой (регистрируется в `DOORS_REGISTRY`).
  - `type: 'open'` — открытый арочный проход без дверного полотна.
- Все сплошные сегменты стен автоматически регистрируются в `WALLS_REGISTRY` для проверки коллизий.

### Создание плит перекрытий
```javascript
addFloorRect(targetGroup, x1, z1, x2, z2, isCore)
```
- `isCore = false` — стандартный пол этажа (светлый).
- `isCore = true` — тонированный пол лифтового узла, санузлов или лестниц.

### Добавление номеров кабинетов и подписей
```javascript
addTextRoomLabel(targetGroup, text, x, z, roomNum, bldg, floor, customColor)
```
- Подписи автоматически проецируются на Screen-Space Retina Overlay Canvas (`#labels-overlay-canvas`) со 100% честной резкостью.
- Имя кабинета регистрируется в глобальном `ROOMS_REGISTRY` для работы поисковой строки.

## 5. Синхронизация с навигационным графом (`js/navigator.js`)

При добавлении, перемещении или удалении стен, дверей и кабинетов необходимо синхронизировать граф в `buildCollegeNavGraph()`:

1. **Узел кабинета (`type: 'room'`)**:
   - `id`: уникальный ключ, например `b1_f2_r208`
   - `label`: `"208"` (или `"Гардероб"`, `"Библиотека"`)
   - `floor`: номер этажа (1–7)
   - `bldg`: номер корпуса (1–4)
   - `x`, `z`: центр кабинета (должен совпадать с координатами `addTextRoomLabel`)
2. **Узел двери (`type: 'corridor'`)**:
   - Располагается строго по центру дверного проема в стене (или на оси коридора напротив проема, чтобы ребро комната ↔ коридор проходило ровно через проем).
   - Соединяется ребром с узлом кабинета и с центральной осью коридора.
3. **Лестницы и лифты (`type: 'stair'`, `type: 'elevator'`)**:
   - Вертикальные сквозные шахты (ЛК-1, ЛК-2, ЛК-3) должны иметь строго совпадающие координаты `x` и `z` на всех этажах, через которые они проходят.
