# MGKCT 3D — Интерактивная 3D-карта и навигатор по колледжу

Веб-сервис внутренней навигации и поэтажных планов Минского государственного колледжа цифровых технологий (МГКЦТ).

### [Demo](https://arseniizyk.github.io/mgkct-3d/)

## Возможности

<h3>
    <ul> 
        <li>Маршрутизация по алгоритму A*
        <li>Поддержка лифтов для маломобильных посетителей
        <li>Переключение между 2D и 3D режимами
        <li>Умный поиск аудиторий и расписания
        <li>Поиск кабинетов по преподавателям
        <li>Энергоэффективный On-Demand рендеринг
        <li>Быстрые точки в один клик
        <li>Карточка маршрута и время в пути
        <li>Четкие Retina-подписи без размытия
        <li>Сенсорное управление на смартфонах
        <li>Темная и светлая темы оформления
        <li>Встроенный визуальный редактор графа
    </ul>
</h3>

## Быстрый старт

Проект не требует сборщиков и работает как статический сайт:

```bash
# Встроенный сервер на Node.js
node serve.js

# Либо стандартный сервер Python
python3 -m http.server 8080
```

Приложение открывается по адресу `http://localhost:8080/`.

### Параметры URL
- `?bldg=1&floor=2` — прямой переход на выбранный корпус и этаж.
- `?top=1` — принудительный запуск в 2D-режиме (вид сверху).
- `?debug=1` — режим отладки с показом координатной сетки, векторов дверей и чертежей БТИ.
- `?grid=1` — отображение метровой мировой сетки (X, Z).
- `?sideBySide=1` — параллельный просмотр 3D-модели и плана БТИ.

## Технические подробности

### Архитектура и стек
- **Three.js (r128)**: рендеринг 3D-геометрии (стены с фиксированной высотой `0.35м`, перекрытия, двери, лестницы, внешняя территория и трубки маршрута).
- **Двухслойный рендеринг**: WebGL-холст для сцены и отдельный `Canvas 2D` оверлей для отрисовки меток с экранной плотностью пикселей (Retina up to 2.5x).
- **OrbitControls**: кастомное управление с жестким ограничением координат (`clampCameraBounds`), предотвращающее переворот ракурса и срыв камеры в 2D.
- **A* Pathfinding**: алгоритм поиска пути по графу на базе двоичной кучи (`MinHeap`) с штрафами за смену этажей.
- **Пространственный индекс стен**: кэширование отрезков стен по корпусам и этажам (`getWallsSpatialIndex`), ускоряющее проверку пересечений лучей.
- **Изоляция стилей и FOUC**: критические стили позиционирования вшиты в CSS; переходы отключены до первого кадра через класс `body:not(.ui-ready)`.
- **Zero-Bundler**: отсутствие Webpack/Vite, нативные скрипты с предсказуемым порядком загрузки в `index.html`.
- **Бэкенд телеметрии**: Cloudflare Workers + D1 (`telemetry_worker/worker.js`) для анонимного учета поисковых запросов и активности.

### Координатная система
- Единицы измерения: метры.
- Ось X: Запад (-) → Восток (+).
- Ось Y: Высота (`y = (floor - 1) * 2.65`).
- Ось Z: Север (-) → Юг (+).

### Структура репозитория
```
mgkct-3d/
├── index.html            # Главная точка входа приложения
├── stats.html            # Панель аналитики посещаемости
├── serve.js              # Встроенный dev-сервер
├── css/                  # Модульные таблицы стилей (10 файлов, ≤300 строк каждый)
├── js/
│   ├── state.js          # Состояние приложения, реестры стен, комнат и дверей
│   ├── telemetry.js      # Клиент сбора метрик
│   ├── materials/        # Материалы Three.js и текстуры расписания (5 файлов)
│   ├── helpers/          # Построители плит, стен, стыков, лестниц и меток (9 файлов)
│   ├── buildings/        # Поэтажная 3D-геометрия корпусов 1–5 (15 файлов)
│   ├── territory/        # Геометрия прилегающей территории, дорог и деревьев (14 файлов)
│   ├── controls/         # Камера, границы и сенсорное управление (2 файла)
│   ├── nav/              # Граф (nav/data/*), алгоритм A*, 3D-путь и UI навигатора (24 файла)
│   ├── ui/               # Темы, поиск, режимы этажей и модальные окна (10 файлов)
│   └── main/             # Инициализация сцены, окклюзия и цикл рендера (6 файлов)
├── node_editor/          # Визуальный редактор графа
├── planning_zip/         # Эталонные чертежи планов БТИ
├── telemetry_worker/     # Серверная часть Cloudflare Workers + D1
└── tests/                # Набор автотестов, валидаторов и VM-загрузчик (tests/helpers/vm_loader.js)
```
