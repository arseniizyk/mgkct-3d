# MGKCT 3D — Интерактивная 3D-карта колледжа с навигатором

Интерактивная 3D/2D карта колледжа МГКЦТ с системой внутренней навигации (4 корпуса, 7 этажей), оптимизированная для мобильных телефонов и десктопа.

## 🚀 Демонстрация (Live Demo)
👉 **https://arseniizyk.github.io/mgkct-3d/**

## ✨ Основные возможности
- **Полноценная внутренняя навигация (Indoor Navigator)**:
  - Построение кратчайших маршрутов между любыми кабинетами, залами и входами на базе алгоритма A*.
  - Учёт вертикальных перемещений (лестницы ЛК№1–ЛК№3) и надземных переходов между корпусами на 2 этаже.
  - Опция «Использовать лифты» (по умолчанию выключена, маршрут ведёт через лестницы).
  - Прокладка путей строго через дверные проёмы без пересечения стен.
  - Пошаговые карточки пути и быстрые кнопки частых точек (главный вход, столовая, спортзал, актовый зал, ближайший туалет).
- **Вид сверху и 3D изометрия**: минимальная высота стен (`0.35м`) для удобного чтения планировки как в Яндекс/Google Картах.
- **Поэтажный селектор**: быстрое переключение между 1–7 этажами с плавной анимацией и нулевой нагрузкой на GPU.
- **Кристально чёткие номера кабинетов (Screen-Space Retina 2D)**:
  - Текст и границы рендерятся в честном разрешении дисплея смартфона без субпиксельного размытия.
  - Динамическое масштабирование: плашки закреплены в границах стен и масштабируются при зуме.
- **Умный поиск по корпусам**:
  - Быстрый поиск формата `2-105`, `1-105`, `4-102`, `к2 204` с автоматическим переходом на нужный этаж и корпус.
- **Сенсорное управление для смартфонов**: свайп одним пальцем, зум щипком, быстрый компас на Север.

## 🛠 Технологии
- Three.js (3D рендеринг геометрии и траектории маршрута)
- Custom Graph & A* Algorithm (поиск пути)
- HTML5 Canvas 2D Retina Overlay
- Tailwind CSS & Google Fonts (Inter)
